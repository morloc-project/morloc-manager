Work through the two tutorials: tutorial-deployment.asc and tutorial-development.asc.

No setup required, following the first tutorial will setup the environment. Use
the latest version of morloc-manager. Also use the latest version of morloc
except when explicitly testing building environments with older versions and
switching.

## Goal 1: report issues

 - bugs in morloc-manager or morloc
 - suggestions for improving morloc-manager or morloc
 - accuracy of the tutorials, flow and completeness
 - the big picture - how could the morloc language and morloc-ecosystem improve?

What NOT to report

 - issues in previous versions of morloc
 - the issue that `morloc make --install` should be file exclusive by
   default. we've decided to include all files by default and exclude via
   .morlocignore, the user is responsible for ignoring secrets and installing
   from the appropriate directories.

## Goal 2: high-level analysis

 - describe the value of morloc-manager and morloc at a high-level
 - add constructive critiques:
   - what could make the system better?
   - what major features are missing?

Extra notes:

 - if there are prior installs of morloc manager, just swing with it, that is
   normal. Assume you are a returning user. If the state is already broken when
   you start, keep notes and thoughts on how you fix it, this is part of the
   testing process.

 - In general, all logs, messages, errors, etc should go to stderr. All primary
   output should go to stdout.

 - Explore beyond the exact replication of the tutorial. Try things that are not
   explicitly covered. Experiment. Tweak things and look for problems. Try to
   anticipate things people might try.

 - Never install from the home directory.
